# BudgetWise CLI

## Project Description
BudgetWise CLI is a command-line personal finance tracker developed in Python. It allows users to record income and expenses, monitor transactions, search financial records, and generate financial summaries.

This project demonstrates intermediate Python programming concepts including object-oriented programming, file handling, data structures, and data processing.

---

## Features
- Add income and expense transactions
- View transaction history
- Search transactions by category
- Generate monthly financial summary
- Save and load transaction data using JSON
- Command-line interface interaction

---

## Technologies Used
- Python 3
- JSON File Storage
